# BoxService — Documentación del proyecto

BoxService es un sistema de gestión para talleres mecánicos que permite administrar clientes, vehículos, presupuestos, servicios y facturación desde una única plataforma.

El proyecto busca modernizar y centralizar el trabajo diario del taller, manteniendo la información organizada y facilitando el seguimiento de cada vehículo desde su ingreso hasta la entrega final.

## Flujo principal

1. Registro del cliente.
2. Registro del vehículo.
3. Creación del presupuesto.
4. Aprobación del presupuesto.
5. Creación y seguimiento del service.
6. Inspección del vehículo mediante fotografías y checklist.
7. Facturación del trabajo realizado.
8. Registro del service en el historial del vehículo.

## Estado general

El proyecto se encuentra en desarrollo. Ya se completaron las migraciones principales del frontend y el backend, la autenticación con roles, el rediseño del inicio de sesión y distintas mejoras operativas. Actualmente se trabaja en las migraciones de base de datos y en el módulo de fotografías y checklist del vehículo.
